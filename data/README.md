# Dataset

This project uses the **Toronto Emotional Speech Set (TESS)** dataset for speech emotion recognition.

## Emotion Categories

The project uses the following seven emotion categories:

* Angry
* Disgust
* Fear
* Happy
* Neutral
* Pleasant Surprise
* Sad

## Dataset Availability

The audio dataset is **not included in this GitHub repository**.

Please obtain the TESS dataset separately and place it on your local machine before running the notebook.

## Using the Dataset

After obtaining the dataset:

1. Extract the dataset on your computer.
2. Update the dataset path in the notebook to match your local folder.
3. Run the notebook to load the audio files and extract MFCC features.

> The notebook currently contains a local Windows dataset path, so this path needs to be changed when running the project on another computer.
